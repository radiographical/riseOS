riseOS

One ecosystem. Multiple devices. Built on Linux.

riseOS is a conceptual open-source operating system ecosystem designed to bridge desktop Linux and Android through a unified vision of performance, customisation, and seamless cross-device integration.

Built around the Linux kernel, riseOS aims to bring together a carefully tuned Fedora-based desktop experience and an Evolution X-based Android experience, creating two distinct environments connected by a shared philosophy and, eventually, a common ecosystem.

Vision

The goal of riseOS is to create an operating system experience that feels consistent across devices without compromising the strengths of either platform.

- Performance — prioritising responsiveness, efficiency, stability, and balanced resource utilisation.
- Customisation — developing a distinctive, cohesive interface and a system that gives users meaningful control.
- Integration — working towards seamless connectivity between desktop computers and mobile devices.
- Openness — building on established open-source projects while contributing original improvements back where possible.
- Reliability — favouring maintainable modifications, reproducible builds, and long-term security over unnecessary complexity.

Core Projects

- riseOS Kernel — a collection of targeted kernel configurations and modifications for desktop Linux and supported Android devices.
- riseOS Desktop — a Fedora-based desktop environment focused on a refined, responsive, and cohesive user experience.
- riseOS Mobile — an Android-based experience built around Evolution X and compatible device-specific kernel development.
- riseOS Connect — a planned cross-device integration layer intended to connect desktop and mobile experiences.

Development Philosophy

riseOS is a work in progress. Development begins with establishing reliable, reproducible desktop and mobile foundations before expanding into deeper system modifications and cross-device functionality.

Rather than reinventing existing technology unnecessarily, riseOS builds upon established projects, evaluates changes through testing, and aims to introduce improvements that serve a clear purpose.

Status

Concept and early development.

The initial focus is on custom Fedora kernel development for x86-64 systems and compatible kernel development for the Google Pixel 6 Pro ("raven") running Evolution X.

The broader riseOS ecosystem remains a long-term goal.
